# Drag Translate

웹페이지에서 드래그한 영어를 한국어로 바로 번역하는 Chrome 확장 프로그램입니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 프로젝트 폴더를 선택합니다.

## 사용

1. 일반 웹페이지에서 툴바의 Drag Translate 아이콘을 누릅니다.
2. 아이콘이 회색에서 연두색으로 바뀌면 번역 기능이 활성화된 상태입니다.
3. 영어 문장 또는 단어를 드래그합니다.
4. 사용을 중지하려면 아이콘을 다시 눌러 회색으로 바꿉니다.

일반 웹페이지에서는 팝업이 열리지 않으며 아이콘 클릭만으로 바로 켜고 끕니다.
상태는 열려 있는 모든 일반 웹 탭과 새로 여는 탭에 동일하게 적용됩니다.

아이콘 색상이 바뀌지 않는다면 `chrome://extensions`에서 확장 프로그램의 새로고침 버튼을 누른 뒤,
번역할 웹페이지도 한 번 새로고침해 주세요.

## 참고

- Chrome 설정 페이지(`chrome://...`)와 Chrome Web Store 등 보호된 페이지에서는 확장 프로그램이 실행되지 않습니다.
- 외부 PDF 페이지에서만 아이콘 클릭 시 팝업이 열립니다. **번역 PDF 뷰어로 열기**를 누르면 PDF.js 기반 전용 뷰어에서 문서 안의 영어를 드래그해 번역할 수 있습니다.
- 로컬 `file://` 페이지에서 사용하려면 확장 프로그램 상세 화면에서 **파일 URL에 대한 액세스 허용**을 켜야 합니다.
- Google 번역의 공개 웹 엔드포인트를 사용하므로 네트워크 상태나 서비스 정책에 따라 요청이 제한될 수 있습니다.
- 선택한 텍스트는 번역을 위해 Google 번역 서버로 전송됩니다.
